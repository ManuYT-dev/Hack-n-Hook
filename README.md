# HacknHook

> A pixel-art fishing game created during a hackathon. Grab your fishing rod, explore beautiful waters, catch rare fish, and compete for the biggest catch using either classic controls or our custom-built fishing controller!

---

## About the Game

**HacknHook** is a pixel-art fishing game developed during a hackathon using unity and C#. Players can fish in various locations, collect different fish species, improve their skills, and enjoy a charming retro-inspired world.

The game supports both traditional PC controls and a custom hardware fishing controller built specifically for this project.
[Repository of the Controller](https://github.com/ManuYT-dev/Hack-n-Hook_Controller)

---

## Features

- 🎣 Interactive fishing mechanics
- 🐟 Multiple fish species to discover
- 🎨 Pixel-art graphics
- 🎮 Mouse & keyboard support
- 🔧 Support for a custom-built fishing controller
- 🌊 Relaxing atmosphere and gameplay
- 🏆 Score tracking and catch statistics
